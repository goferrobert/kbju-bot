# 🤖 KBJU Bot - Telegram Bot для расчета КБЖУ и процента жира

Интеллектуальный Telegram бот для расчета калорий, белков, жиров, углеводов (КБЖУ) и точного определения процента жира в организме с использованием продвинутых алгоритмов и адаптивных рекомендаций.

## 🚀 Основные возможности

### 📊 **Точный расчет процента жира**
- **US Navy метод** с корректировками для женщин
- **Анализ мышечной массы** по дополнительным замерам
- **Учет спортивной подготовки** и типа телосложения
- **Корректировка по BMI** для более точных результатов

### 🍽 **Расчет КБЖУ**
- **Метод Katch-McArdle** для точного расчета
- **Адаптация под цели**: здоровье, спорт, сушка
- **Учет физической активности** и образа жизни
- **Персональные рекомендации** по питанию

### 📈 **Комплексный анализ**
- **Метаболический возраст** и базовый обмен веществ
- **Тип телосложения** (эктоморф, мезоморф, эндоморф)
- **Индекс мышечной массы** (FFMI)
- **Соотношение талия/бедра** (WHR)

### 🛡️ **Безопасность и здоровье**
- **Проверки безопасности** для предотвращения РПП
- **Адаптивные рекомендации** для разных категорий пользователей
- **Предупреждения** о критических показателях
- **Мотивационные сообщения** и поддержка

## 📊 Алгоритмы расчета

### **Процент жира (US Navy + корректировки):**
```python
# Для мужчин
bodyfat = 86.010 * log10(waist - neck) - 70.041 * log10(height) + 36.76

# Для женщин
bodyfat = 163.205 * log10(waist + hip - neck) - 97.684 * log10(height) - 78.387
```

### **КБЖУ (Katch-McArdle):**
```python
# LBM = вес * (1 - жир/100)
# BMR = 370 + 21.6 * LBM
# TDEE = BMR * множитель_активности + спорт_калории
```

### **Дополнительные метрики:**
- **BMI** = вес / (рост/100)²
- **WHR** = талия / бедра
- **FFMI** = LBM / (рост/100)²
- **Метаболический возраст** по BMR
